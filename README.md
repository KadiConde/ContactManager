📇 ContactManager Pro
📌 Description du projet

ContactManager Pro est une application web moderne de gestion de contacts développée dans le cadre du cours INFO4042 – Applications Web.
Elle permet aux utilisateurs de créer, organiser, rechercher et gérer leurs contacts de manière simple, sécurisée et efficace.

L’application met en pratique les bonnes pratiques du développement web avec ASP.NET Core MVC, une interface responsive et une authentification sécurisée.

🎯 Objectifs du projet

Concevoir une application web complète et fonctionnelle

Mettre en œuvre l’architecture MVC

Utiliser une base de données relationnelle avec Entity Framework Core

Implémenter l’authentification et la gestion des utilisateurs

Offrir une interface moderne, minimaliste et responsive

Respecter les standards professionnels du développement web

🛠️ Technologies utilisées

ASP.NET Core MVC

Entity Framework Core (Code First)

SQL Server

ASP.NET Identity (authentification et gestion des comptes)

Bootstrap 5

Bootstrap Icons

HTML5 / CSS3

C#

✨ Fonctionnalités principales

Inscription et connexion sécurisées des utilisateurs

Gestion des contacts (ajout, modification, suppression)

Recherche intelligente des contacts

Interface responsive (mobile, tablette, desktop)

Sécurité des données utilisateur

Design moderne et minimaliste de type SaaS

🧱 Architecture du projet

Le projet suit l’architecture MVC (Model – View – Controller) :

Models : définition des entités (Contact, ApplicationUser, etc.)

Views : interface utilisateur (Razor Views)

Controllers : logique métier et gestion des requêtes

Data : contexte de base de données (DbContext)

Areas/Identity : authentification et gestion des comptes

▶️ Instructions d’installation et d’exécution
Prérequis

.NET SDK 6 ou supérieur
